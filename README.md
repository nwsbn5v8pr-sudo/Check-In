# Check-In

A simple, Apple-style customer check-in app for iPhone and iPad.

- Tap **+ Check In** to add a customer: name, what they're wearing, location (A, B, C, GB + 1–6), product, trade-in, and how they'll pay.
- **Up Next** shows each customer's location, wait time, and tags like **Ready to pay**.
- Follows the device's light/dark mode.

## Privacy

Customer info is stored only in the browser on the device using the app — nothing is sent to a server.
Each customer is deleted automatically **1 hour after check-in** (or immediately with Help, Remove or Clear All).

## Install on iPhone or iPad

1. Open the GitHub Pages link in **Safari**.
2. Tap **Share → Add to Home Screen → Add**.

## Products

Only **iPhone** and **Trade-in** are shown right now. iPad, Mac, Apple Watch, Apple Home and Accessories are still saved in `index.html` with all their steps — to bring any back, add its name to the `ACTIVE` list near the top of the script.

iPhone models: DUO, 18 Pro, 18 Pro Max, Air, 17, 17e, 16 (edit the `MODELS` list to change them).
